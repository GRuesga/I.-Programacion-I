Instrucciones - Desafío 1: Palíndromos

Descripción:
Este programa en Python (compatible con Python 3.10 o superior) permite verificar si una palabra o frase ingresada por el usuario es un palíndromo. El algoritmo normaliza el texto eliminando acentos, mayúsculas, espacios y signos de puntuación antes de realizar la comparación.

Requisitos:
- Python 3.10 o posterior.
- No requiere librerías externas (utiliza únicamente la biblioteca estándar de Python: unicodedata y re).

Instrucciones de ejecución:
1. Abre una terminal en la carpeta contenedora del script.
2. Ejecuta el archivo con el siguiente comando:
   python desafio_1_palindromos.py
3. Ingresa la palabra o frase solicitada en la consola para ver el resultado.
